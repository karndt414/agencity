# Balcony Gardening Basics

Tiny static site for beginners who want to garden on an apartment balcony.

## What’s included
- Accessible semantic HTML
- Responsive CSS
- Beginner-friendly planting tips
- Source notes with exact URLs

## Factual notes used
- Container gardening basics and drainage guidance: https://extension.oregonstate.edu/gardening/techniques/container-gardening-basics
- Four keys to container vegetable success: https://extension.psu.edu/container-vegetable-gardening-four-keys-to-success
- Container growing guidance: https://www.pubs.ext.vt.edu/426/426-020/426-020.html
- Container vegetable gardening advice: https://extension.unh.edu/resource/growing-vegetables-containers-fact-sheet
- Container growing overview: https://www.extension.umd.edu/resource/growing-vegetables-containers
- Plant hardiness map use: https://planthardiness.ars.usda.gov/pages/how-to-use-the-maps
- Beginner accessibility guidance: https://www.w3.org/WAI/tips/designing/
- Safe pest control and pesticide safety: https://www.epa.gov/safepestcontrol/citizens-guide-pest-control-and-pesticide-safety
